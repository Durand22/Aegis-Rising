AEGIS RISING — SETTINGS UI ASSETS (Unity)

Contents:
- 00_full_reference_sheet.png: original complete generated reference sheet.
- Separate crops grouped into panels, title, tabs, toggles, dropdowns, sliders, icons, buttons, and misc.

Unity import:
1. Copy this folder under Assets/Art/UI/Settings/.
2. Select PNGs; set Texture Type = Sprite (2D and UI), Sprite Mode = Single.
3. For crisp pixel-art edges use Filter Mode = Point (no filter), Compression = None.
4. Put panel sprites on UI Image objects. Put button normal/selected/pressed sprites into a Unity Button's Transition = Sprite Swap fields.
5. Build text labels, value labels, slider fills, and actual toggle/dropdown behavior with Unity UI components. The crops are visual placeholders, not functional controls.

Note: these are approximate crops from a generated sprite sheet. Some assets may contain extra margins or portions of nearby artwork; inspect and adjust Sprite Editor rectangles before shipping. The original sheet is included for reference.
